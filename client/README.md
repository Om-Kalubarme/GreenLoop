# ReSource AI — Frontend Client Application

The official client application for **ReSource AI — AI-Powered Waste-to-Resource Platform**, built with modern React 18, Vite 6, and Tailwind CSS.

---

## 1. Technologies & Dependencies

- **Framework:** React 18 (Functional components + Hooks)
- **Bundler & Dev Server:** Vite 6
- **Styling:** Tailwind CSS (Custom color tokens, gradients, responsive breakpoints)
- **Icons:** Lucide React (`lucide-react`)
- **Routing:** React Router DOM v6 (`react-router-dom`)
- **HTTP Client:** Axios (`axios`) with Bearer token interceptor
- **Deployment:** Vercel (Edge CDN with SPA route rewrites via `vercel.json`)

---

## 3. Environment Variables

Create `.env` inside `client/`:
```bash
# Backend REST API endpoint (Defaults to localhost:5001/api if omitted)
VITE_API_URL=http://localhost:5001/api
```

---

## 4. Development & Build Scripts

```bash
# 1. Install dependencies
npm install

# 2. Start local development server (http://localhost:5173)
npm run dev

# 3. Build optimized production bundle
npm run build

# 4. Preview local production bundle
npm run preview
```

## 5. Key Features

- **Responsive Grid & Mobile Drawer:** Seamless experience across mobile, tablet, and desktop viewports.
- **Explainable Match Visualization:** Badges display percentage compatibility and human-readable justification reasons generated by the recommendation engine.
- **One-Click Demo Autofill:** Login page features instant demo buttons for Rahul (Donor), Ananya (Recipient), and Admin for effortless viva demonstrations.
- **Fault-Tolerant Media:** Displays Cloudinary hosted assets or local Express uploads with placeholder fallbacks if images fail to load.
